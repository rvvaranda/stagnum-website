# Stagnum Instalações — redesign do site

Protótipo responsivo em HTML, CSS e JavaScript, incluindo parallax, serviços, obras concluídas e identidade visual modernizada.

## Visualização local

```bash
python3 -m http.server 8080
```

Abra `http://localhost:8080`.

## GitHub Pages

Em **Settings → Pages**, configure **Deploy from a branch**, branch `main`, pasta `/ (root)`. Após ativar, o endereço será `https://rvvaranda.github.io/stagnum-website/`.

## Arquivos

- `index.html`: HTML, CSS e JavaScript do protótipo.
- `stagnum-logo-conceito.png`: proposta de modernização da identidade visual.
- `.nojekyll`: publicação estática no GitHub Pages.

> Este é um protótipo. As imagens de obras são ilustrativas e devem ser substituídas pelas fotografias reais e autorizadas antes da versão definitiva.
